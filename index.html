INCREMENTAL

TMDB ONLY SCRAPER

不是“搜到第一条就入库”，而是真正按候选评分刮削

影院刮削使用独立服务：先解析发布文件名和外部 ID，再综合标题、年份、媒体类型、热度和票数选择最佳结果。命中不稳定时，可以在影院详情中查看 TMDB 候选并手动绑定。

  • 支持 tmdb-693134、tt... 等外部标识
  • 自动清洗 2160p、WEB-DL、HEVC、国语中字等发布信息
  • 补全演员、导演、类型、片长、评分、海报与背景图
  • 生成 Emby/Kodi 兼容 NFO，不再回退到其他元数据源
  • 未匹配条目会明确标记，方便手动校准

MATCHING MODEL

候选评分如何工作

维度策略
标题归一化后完全匹配、包含关系与相似度评分
年份完全一致加分；相差 1 年轻微加分；偏差过大扣分
类型电影 / 剧集不一致时直接重罚
质量热度、票数和海报可用性作为辅助信号
兜底低于自动匹配阈值时保持条目可管理，并进入手动校准
隐私边界：GitHub Pages 只发布本页和说明书等静态文件，不包含后端源码、数据库、Cookie、API Key、日志或本机运行数据。

MEDIA PIPELINE

从网盘目录到可播放媒体库

四步完成影院入库，任务中心实时呈现进度；失败条目保留上下文，便于继续和校准。

01 / INDEX

选择 115 目录

直接递归读取 115 目录，并将目录树清单保存在本地输出目录，不再依赖官方导出文件。

02 / STRM

生成媒体结构

在本地生成电影、剧集、季和集目录，以及可长期播放的 STRM 文件。

03 / SCRAPE

TMDB 匹配

独立刮削器识别片名和 ID，拉取完整详情、海报、背景图与 NFO。

04 / PLAY

播放与整理

在 PanMVP 或 Emby 中播放，字幕、弹幕、进度和剧集切换保持可用。

QUICK START

Windows 本机运行，两条命令启动

默认使用本机 Python、Node 和 SQLite；也提供官方 Docker 镜像 xxoo520zls/panmvp:0.2.2。首次启动后在网页中创建管理员账号。

Set-ExecutionPolicy -Scope Process Bypass
.\scripts\local.ps1 setup
.\scripts\local.ps1 start

默认访问地址：http://localhost:8787

Docker 部署可选，一条命令即可启动：

docker run -d --name panmvp -p 8787:8787 \
  -v panmvp-data:/data \
  xxoo520zls/panmvp:0.2.2

FIRST CONFIG

首次使用清单

  1. 创建管理员账号，密码不写死、不默认生成。
  2. 进入“系统设置 → 115 网盘”，扫码或填写 Cookie。
  3. 在高级设置中配置 TMDB API Key，影院刮削固定使用 TMDB。
  4. 在“系统设置 → STRM 生成”配置 115 目录与本地输出目录映射。
  5. 按需配置 TMDB、STRM 根目录、FFmpeg / FFprobe 和网络代理，再进入影院运行刮削任务。
  6. 在任务中心和运行日志中检查每条按钮操作与 API 请求。
版本：官网当前对应 PanMVP 0.2.2。更新日志会记录每项用户可见功能。
