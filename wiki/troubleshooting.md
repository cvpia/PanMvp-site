# 故障排查

## 115 连接异常

1. 检查 Cookie 是否过期。
2. 点击“刷新信息”和“检测连接”。
3. 检查代理是否能访问 `115.com` 与 `webapi.115.com`。

## TMDB 无结果

1. 测试 TMDB 网络。
2. 检查 API Key。
3. 搜索时补充年份和类型。
4. 在影院详情页手动选择候选。

## 播放异常

1. 在 302 和代理播放之间切换。
2. 检查 Range 响应和网络代理。
3. HLS 场景检查 FFmpeg 路径。

## 提交问题时

请提供版本、操作步骤和脱敏日志。不要上传 Cookie、API Key、数据库或隐私截图。
