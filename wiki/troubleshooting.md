# 故障排查

## 115 连接异常

1. 检查 Cookie 是否过期。
2. 点击“刷新信息”和“检测连接”。
3. 检查代理是否能访问 `115.com` 与 `webapi.115.com`。

## TMDB 无结果

1. 在“系统设置 → 基础设置”填写网络代理，并确认代理能访问 `api.themoviedb.org` 与 `image.tmdb.org`。
2. 检查 API Key。
3. 搜索时补充年份和类型。
4. 在影院详情页手动选择候选。
5. 日志出现 `All connection attempts failed` 说明出口不通：界面里配置的网络代理会作用于全部外部请求。

## 播放异常

1. 在 302 和代理播放之间切换。
2. 检查 Range 响应和网络代理。
3. HLS 场景检查 FFmpeg 路径。

## 聚影资源搜索提示未登录

1. 确认“系统设置 → 资源登录”保存过聚影账号和密码。
2. Token 失效时系统会自动重新登录；若仍失败，检查账号密码和网络代理。
3. 查看运行日志中的聚影 HTTP 状态码与错误信息，不要提交密码或 Token。

## 资源添加没有弹出目录窗口

这是默认行为：系统会直接使用 115 默认转存目录。需要逐次选择目录时，在“系统设置 → 基础设置”开启“资源添加时显示目录选择弹窗”。如果默认目录尚未设置，系统会先要求设置一次默认目录。

## 提交问题时

请提供版本、操作步骤和脱敏日志。不要上传 Cookie、API Key、数据库或隐私截图。
