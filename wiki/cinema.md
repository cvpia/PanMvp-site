# 影院与 TMDB 刮削

影院刮削固定使用 TMDB，不再回退其他元数据源。

## 自动刮削

1. 在系统设置中配置全局或当前用户的 TMDB API Key。
2. 进入影院，选择 115 来源目录。
3. 运行目录树、STRM 和刮削任务链。
4. 在任务中心查看进度和未匹配数量。

## 匹配策略

- 清洗分辨率、编码、发布组和语言信息。
- 识别 TMDB ID、IMDb ID、年份和季集号。
- 按标题、年份、类型、热度、票数和海报综合评分。
- 低于自动匹配阈值时进入手动校准。

## 手动校准

在影院详情页点击“手动校准刮削”，输入标题、年份和类型，搜索 TMDB 候选。点击候选后保存，会同步更新数据库、NFO、海报和背景图。
