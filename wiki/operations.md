# 任务、日志与运维

## 任务中心

- 查看排队、执行中、已完成、失败和暂停任务。
- 影院 STRM / 刮削支持断点继续。
- STRM 映射任务显示全量或增量模式、生成数、跳过数和清理数。
- 订阅任务支持重试。
- 一键删除会停止运行中任务并删除当前账号任务记录。

## 运行日志

日志按日保存，记录：

- 按钮动作
- API 请求、状态码、耗时和请求 ID
- 任务开始、完成和失败
- 影院图片、刮削和播放事件

可在日志页面设置保留天数和每日清理时间。

## 资源转存与订阅

- 资源添加默认使用 115 默认转存目录，不强制弹出目录选择窗口。
- 系统设置中的“资源添加时显示目录选择弹窗”默认关闭；开启后每次添加资源都会先选择目录。
- 默认目录未设置时，添加资源会先弹出默认目录设置窗口，保存后自动继续。
- 磁力链接和电驴链接统一提交 115 云下载；多链接时选择文件最大的链接。
- 聚影 Token 失效时自动使用已保存账号密码重新登录并重试。
- “转存成功 / 已转存资源”页面集中展示订阅成功转存和云下载记录。

## 版本信息

- 登录页、初始化页和控制台顶栏显示当前 PanMVP 版本号。
- 版本号由后端读取仓库根目录 `VERSION`，Docker 镜像由 `APP_VERSION` 构建参数注入。

## 115 资料展示

- 115 资料卡通过本机后端代理读取真实网盘头像，避免浏览器直接加载时的防盗链问题。
- 会员状态优先显示到期时间；永久 VIP 显示金色“永久会员”标识。

## 备份

建议定期备份：

- `data/panmvp.db`
- `data/local.secret`
- 自定义 STRM 根目录和媒体元数据
- 本地输出目录中的 `.panmvp/directory-tree.json` 目录树清单
- Docker 部署时持久化数据卷 `panmvp-data`（包含数据库、密钥和日志）

Docker 部署可用下面的命令导出数据卷：

```powershell
docker run --rm -v panmvp-data:/data -v ${PWD}:/backup alpine `
  tar czf /backup/panmvp-data.tgz -C /data .
```

不要将备份文件上传到公开 GitHub 仓库。
