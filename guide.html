WIKI / PANMVP 0.2.0

PanMVP 使用说明书

从首次运行到 115 账号、播放、影院刮削、任务和日志排障。适用于 Windows 本机运行，不依赖 Docker。

快速开始

推荐使用项目自带的 PowerShell 脚本：它会创建 backend/.venv、安装依赖、构建 Vite 前端并启动 FastAPI。

Set-ExecutionPolicy -Scope Process Bypass
.\scripts\local.ps1 setup
.\scripts\local.ps1 start

浏览器打开 http://localhost:8787，首次运行会引导创建管理员账号。常用命令：

.\scripts\local.ps1 status
.\scripts\local.ps1 start -Reload
.\scripts\local.ps1 test
.\scripts\local.ps1 stop
发布提示：PanMVP 官网与 Wiki 是纯静态站点。访问官网不会连接你的本机数据库，也不会下载或公开源码。

安装与升级

环境要求

  • Windows 10 / 11 或可运行 Python、Node 的 Windows 环境。
  • Python 3.12+；项目默认使用 backend/.venv。
  • Node.js 20+；项目可使用仓库内 .tools/npm。
  • 可选：FFmpeg / FFprobe，用于 HLS、字幕和媒体探测。

手动开发运行

cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[test]"
uvicorn app.main:app --reload --port 8787
cd frontend
npm install
npm run dev

升级

获取新版本后重新执行 .\scripts\local.ps1 setup，再启动服务。数据库和 data/ 目录会保留；升级前建议备份 data/panmvp.db。

115 网盘配置

  1. 进入“系统设置 → 115 网盘”。
  2. 推荐选择扫码客户端，点击“获取二维码”，用 115 App 完成扫码确认。
  3. 登录成功后检查头像、用户名、账号 ID、VIP、到期时间和空间使用情况。
  4. 设置默认转存目录，点击“保存账号设置”。

Cookie 直填

也可以填写类似下面的 Cookie。Cookie 只会加密写入本机 SQLite，前端不会回显原文。

UID=...; CID=...; SEID=...; KID=...
安全：不要把 Cookie 发到公开聊天、截图、Issue 或 GitHub Pages。该信息等同于账号会话凭据。

文件管理页面的网盘标签

标签会显示“115 网盘 + 网盘用户名 + 账号 ID”，便于区分多个账号和排查连接状态。

文件管理

操作说明
浏览 / 打开进入 115 文件夹，根目录开始按真实目录浏览。
下载单选文件，通过签名票据下载，支持 115 直链解析。
批量重命名先预览新旧名称，再确认执行；不会绕过 115 官方接口。
批量分享调用 115 官方分享接口，可设置标题、提取码和有效期。
删除支持多选删除；根目录不会删除。
播放支持常见视频文件进入 PanMVP 播放器。
官方目录树只对 115 Cloud 驱动开放，用于影院入库和批量扫描。

涉及写操作前会弹出确认，并记录按钮动作日志；API 请求和错误也会出现在运行日志页面。

播放链路

302 直链

服务端解析 115 播放地址并返回 HTTP 302。浏览器直接从网盘读取媒体流，服务器压力较小，适合大多数家庭网络。

代理播放

兼容防盗链或局域网问题，服务端完整转发 Range、Content-Range、Accept-Ranges 和 206 响应，支持拖动。

HLS 回退

302 失效时，可使用本机 FFmpeg 生成 HLS。多音轨会被映射为可切换轨道，缓存会在播放结束后清理。

场景建议
家庭内网、直链可用使用 302，速度最快。
播放器提示 403 / 源站防盗链切换代理播放或检查网络代理。
需要多音轨 / 字幕转码配置 FFmpeg / FFprobe 并使用 HLS。

影院与 TMDB 刮削

v0.2.0 的影院刮削固定使用 TMDB，不再回退其他元数据源。首次使用前请在“系统设置 → 高级设置”配置全局 TMDB API Key，或在个人偏好中配置个人 Key。

入库流程

  1. 点击“影院 → 入库 115 目录”。
  2. 选择一个或多个来源目录，确认是否删除所选来源的旧本地 STRM。
  3. 系统依次创建目录树、STRM 生成和刮削任务。
  4. 任务中心显示每阶段进度；完成后影院卡片实时出现。

独立 TMDB 刮削器

  • 清洗分辨率、编码、发布组、语言等发布文件名信息。
  • 识别 TMDB ID、IMDb ID、年份和剧集季集号。
  • 按标题、年份、类型、热度、票数和海报信息评分候选。
  • 补全详情、演员、导演、类型、片长、评分、海报和背景图。
  • 生成 Emby / Kodi 兼容 NFO。

手动校准

在影院详情页点击“手动校准刮削”，输入标题、年份和类型，搜索 TMDB 候选。点击候选卡片后，系统会绑定 TMDB ID，保存时同步更新数据库、NFO、海报和背景图。

没有 TMDB Key：影院条目仍可显示原始解析结果，但无法自动补全元数据和海报；搜索候选会提示“请先配置 TMDB API Key”。

任务中心与运行日志

任务中心

显示执行中、已完成、失败和暂停状态。影院任务支持断点继续；订阅任务支持重试。新版本提供“一键删除”，确认后会停止运行中任务并删除当前账号任务记录。

一键删除不可恢复：删除的是任务记录；已经生成的本地 STRM、NFO、海报等文件需要到影院来源管理中处理。

运行日志

日志包含按钮动作、API 请求、任务执行、状态码、耗时、用户和错误。日志按日保存，可在页面设置保留天数和每日清理时间。

日志类型用途
button_action记录页面按钮点击及上下文。
http_request记录 API 路径、方法、状态码、耗时和请求 ID。
task / cinema / playback记录任务执行、影院刮削和播放相关事件。

通知渠道

支持 Telegram、企业微信、钉钉、邮件和通用 Webhook。配置后，任务完成或失败可发送通知；通知凭据加密保存。

  • Telegram：填写 Bot Token 和 Chat ID。
  • 企业微信 / 钉钉：填写机器人 Webhook。
  • 邮件：填写 SMTP 地址、账号、密码和收件人。
  • 通用 Webhook：适合接入自建服务或自动化平台。

安全与隐私

  • 为生产环境设置稳定的 PANMVP_SECRET_KEY，用于加密 115 Cookie、通知凭据和 TMDB Key。
  • 不要把 .env、data/panmvp.db、Cookie、日志或截图提交到公开仓库。
  • GitHub Pages 只部署 docs/ 静态站点，不包含后端源码或运行数据。
  • 公网访问时应在反向代理层启用 HTTPS，并限制管理接口来源。
  • 资源搜索依赖用户自行配置的账号；PanMVP 不内置或分发盗版资源。

故障排查

115 显示连接异常

  1. 检查是否已扫码或填写 Cookie。
  2. 在 115 网盘设置中点击“刷新信息”和“检测连接”。
  3. 若 Cookie 过期，重新扫码登录。
  4. 检查系统代理是否能访问 115.com 和 webapi.115.com。

影院刮削没有海报或信息

  1. 确认已配置 TMDB API Key，并在设置中测试网络。
  2. 检查文件名是否包含可识别片名、年份或 TMDB/IMDb ID。
  3. 在影院详情中使用“手动校准刮削”选择正确候选。
  4. 查看运行日志中 cinema_poster、cinema_scrape 的错误信息。

播放卡顿 / 无法拖动

  1. 切换 302 / 代理播放模式。
  2. 检查网络带宽和代理稳定性。
  3. 拖动失败时确认服务端代理是否透传 Range。
  4. HLS 场景检查 FFmpeg 路径是否可执行。

任务一直排队或失败

  1. 查看任务卡片的错误和运行日志。
  2. 确认数据库目录可写、磁盘空间充足。
  3. 影院任务失败后可使用“继续”从断点恢复。
  4. 必要时删除任务后重新创建任务链。

常见问题

可以部署到公网服务器吗？

PanMVP 当前只支持本机运行。若通过反向代理暴露，请自行启用 HTTPS、访问控制和备份策略。

官网会公开源码吗？

不会。GitHub Pages 工作流只上传 docs/ 目录中的静态网站文件。后端、数据库、日志和凭据不会进入 Pages artifact。

为什么影院刮削必须是 TMDB？

为了统一元数据结构、减少错误匹配并稳定生成 Emby/Kodi 兼容 NFO，影院链路只使用 TMDB。发现和订阅模块仍可保留其他来源。

如何反馈问题？

提交问题时请附版本号、操作步骤和脱敏后的运行日志。不要上传 Cookie、API Key、数据库或包含隐私的截图。
