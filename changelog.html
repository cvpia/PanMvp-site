RELEASE NOTES

PanMVP 更新记录

每次面向用户的功能变更都会同步到官网、版本页和 Wiki。当前官网对应 PanMVP 0.2.1。

v0.2.1 LATEST

2026-10-10

本版本重构目录树与 STRM 生成方式，移除文件管理中的 115 官方目录树入口，并完善本地目录选择和 115 个人资料展示。

新增功能
  • 系统设置新增“STRM 生成”，支持一条或多条 115 目录到本地目录的映射。
  • 新增“目录树 + STRM 全量生成”，重新扫描并重建全部 STRM。
  • 新增“直接 STRM 增量生成”，跳过未变化文件并清理来源中已删除的旧 STRM。
  • 本地输出目录保存 .panmvp/directory-tree.json 目录树清单。
  • 115 和本地目录选择器都支持弹窗浏览与新建文件夹。
  • 新增旧官方目录树文件与本地缓存清理操作。
体验改进
  • 文件管理移除“115 官方目录树”按钮，职责集中到系统设置。
  • 影院和 STRM 流程直接递归读取 115 目录，不再等待官方导出任务。
  • 115 资料卡显示用户名、账号 ID、会员、到期、总容量、已用和剩余空间。
  • 115 空间数据改为读取个人资料与空间接口，刷新后立即更新。
  • 旧官方目录树缓存不再参与后续生成，避免混用。
安全与清理
  • 旧官方目录树清理只处理名称包含“目录树”的导出文件，不删除媒体。
  • 删除 STRM 映射默认保留已生成的本地 STRM 和目录树文件。
  • 版本号同步更新为 0.2.1。

v0.2.1 · Docker 镜像 NEW

2026-10-11

应用代码仍为 0.2.1，本次补充官方镜像分发与 Docker 部署文档，程序功能、接口和数据库结构均未改动。

镜像分发
  • Docker Hub 发布官方镜像 xxoo520zls/panmvp:0.2.1 与滚动标签 latest。
  • 镜像内置 Python 3.12、FFmpeg 和已构建前端，宿主机无需安装 Python、Node 或 FFmpeg。
  • 默认数据目录为容器内 /data，挂载数据卷即可持久化数据库、密钥和日志。
文档
  • Wiki 新增“Docker 镜像部署”章节：端口、数据卷、环境变量、STRM 目录挂载、运维、升级与备份。
  • 官网首页快速开始与安装入口补充 Docker 方式，并说明容器内路径与宿主机挂载路径的区别。
兼容性
  • Windows 本机运行方式保持不变，两种方式的 SQLite 数据结构一致。
  • 版本号仍为 0.2.1，未发布新的应用版本。

v0.2.0

2026-10-10

本次版本重点是重新定义影院刮削体验，同时补齐任务清理、115 账号资料展示和项目官网。

新增功能
  • 独立 TMDB 刮削器，支持文件名清洗、外部 ID 识别和候选评分。
  • 影院详情新增 TMDB 候选搜索与手动绑定。
  • 任务中心新增“一键删除”，可清理全部任务记录。
  • 115 设置升级为资料卡，显示头像、用户名、VIP、到期和空间。
  • 文件管理网盘标签改为“115 网盘 + 用户名 + 账号 ID”。
  • 新增 GitHub Pages 官网、Wiki 说明书和版本更新页。
体验改进
  • 刮削改为按标题、年份、类型、热度和票数综合选择，不再直接使用第一条结果。
  • NFO 扩展演员、导演、编剧、类型、票数、唯一 ID、首播日期等字段。
  • 影院刮削同时缓存海报和背景图。
  • 未匹配条目会明确统计和提示，可进入手动校准。
  • 按钮动作、API 请求和任务日志保持可查询。
安全与边界
  • GitHub Pages 只上传 docs/ 静态站点。
  • 不发布后端源码、数据库、Cookie、API Key、日志或运行数据。
  • 影院刮削链路统一使用 TMDB，不再回退其他元数据源。
  • 版本号同步更新为 0.2.0。

v0.1.2

2026-10-10

本机运行与日志能力完善版本。

  • 加入按日运行日志，记录按钮动作、API 请求、状态码、耗时和用户。
  • 日志支持保留天数与每日清理时间。
  • 完善 Windows 本机启动、测试和停止脚本。
  • 完善 115 Cookie、扫码登录、用户信息和空间展示。
  • 改善影院 STRM、字幕、弹幕和播放链路。

v0.1.0

2026-10-02

PanMVP 初始版本，建立本地优先的 115 网盘媒体控制中枢。

  • FastAPI + Vue 3 + SQLite 基础架构。
  • 115 文件管理、资源搜索、订阅和通知。
  • 302/代理播放、HLS 回退和播放进度。
  • 基础影院 STRM、NFO 与 Emby 工作流。

发布规范

项目约束要求所有面向用户的功能变更同步更新官网、版本页和 Wiki。发布前必须使用本机浏览器验证桌面端和移动端导航、按钮、复制命令和页面链接。

GitHub Pages 边界：Pages workflow 只部署 docs/ 目录，不会上传后端源码、.env、数据库、日志或用户凭据。
