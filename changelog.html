RELEASE NOTES

PanMVP 更新记录

每次面向用户的功能变更都会同步到官网、版本页和 Wiki。当前官网对应 PanMVP 0.2.0。

v0.2.0 LATEST

2026-10-10

本次版本重点是重新定义影院刮削体验，同时补齐任务清理、115 账号资料展示和项目官网。

新增功能
  • 独立 TMDB 刮削器，支持文件名清洗、外部 ID 识别和候选评分。
  • 影院详情新增 TMDB 候选搜索与手动绑定。
  • 任务中心新增“一键删除”，可清理全部任务记录。
  • 115 设置升级为资料卡，显示头像、用户名、VIP、到期和空间。
  • 文件管理网盘标签改为“115 网盘 + 用户名 + 账号 ID”。
  • 新增 GitHub Pages 官网、Wiki 说明书和版本更新页。
体验改进
  • 刮削改为按标题、年份、类型、热度和票数综合选择，不再直接使用第一条结果。
  • NFO 扩展演员、导演、编剧、类型、票数、唯一 ID、首播日期等字段。
  • 影院刮削同时缓存海报和背景图。
  • 未匹配条目会明确统计和提示，可进入手动校准。
  • 按钮动作、API 请求和任务日志保持可查询。
安全与边界
  • GitHub Pages 只上传 docs/ 静态站点。
  • 不发布后端源码、数据库、Cookie、API Key、日志或运行数据。
  • 影院刮削链路统一使用 TMDB，不再回退其他元数据源。
  • 版本号同步更新为 0.2.0。

v0.1.2

2026-10-10

本机运行与日志能力完善版本。

  • 加入按日运行日志，记录按钮动作、API 请求、状态码、耗时和用户。
  • 日志支持保留天数与每日清理时间。
  • 完善 Windows 本机启动、测试和停止脚本。
  • 完善 115 Cookie、扫码登录、用户信息和空间展示。
  • 改善影院 STRM、字幕、弹幕和播放链路。

v0.1.0

2026-10-02

PanMVP 初始版本，建立本地优先的 115 网盘媒体控制中枢。

  • FastAPI + Vue 3 + SQLite 基础架构。
  • 115 文件管理、资源搜索、订阅和通知。
  • 302/代理播放、HLS 回退和播放进度。
  • 基础影院 STRM、NFO 与 Emby 工作流。

发布规范

项目约束要求所有面向用户的功能变更同步更新官网、版本页和 Wiki。发布前必须使用本机浏览器验证桌面端和移动端导航、按钮、复制命令和页面链接。

GitHub Pages 边界：Pages workflow 只部署 docs/ 目录，不会上传后端源码、.env、数据库、日志或用户凭据。
